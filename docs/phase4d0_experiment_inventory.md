# Phase 4D-0 — Experiment Inventory

## Scope and conventions

This inventory is a read-only reconstruction from the final Phase 1–4C reports, frozen configs, manifests, and statistics already present in the repository. No model was run, no sealed split was opened, and no historical result was rewritten. `FG IoU` means per-image foreground IoU unless a row explicitly says global-pixel aggregation. The localization target is the official SynthScars polygon-derived per-image all-reference union of visible/explainable artifacts; it is not a pseudo-mask and is not pixel-perfect ground truth for every forged pixel.

## Inventory-level conclusions

1. The only current deployable localization method with a statistically supported matched improvement is P1 / Stage-I Phrase-Aligned Forensic SFT.
2. Phase 3 post-training variants did not add a supported second deployable method.
3. Phase 4C-A establishes representation learnability under matched validation probing; Phase 4C-C blocks the stronger claim that the present Reader transfers that representation image-specifically or spatially.
4. Historical internal-test and official1000 results may be cited as already completed facts, but Phase 4D-0 did not reopen either sealed population.
