LAUNCH-TIME BLOCKERS IN STOCK SCRIPT
1. infer.sh does not set PYTHONPATH; root invocation cannot import eval/model packages.
2. infer.sh launches plain python, while infer.py unconditionally constructs DistributedSampler.
3. default local_rank=-1 is passed as sampler rank; no process group is initialized by stock shell.
4. flat folder is not filtered; any non-image/subdirectory reaches cv2.imread and can fail.
5. GPU is implicit current CUDA device; no CUDA_VISIBLE_DEVICES in infer.sh.

These are audit findings only. No official source was patched.
