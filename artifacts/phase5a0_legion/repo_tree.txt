Directory roles:
- scripts/loc_exp: localization + explanation train/inference entry points.
- scripts/cls: separate binary detection head train/eval entry points.
- scripts/merge_weights: DeepSpeed consolidation and PEFT LoRA merge to HF format.
- model: GLaMM/LLaVA-derived LLM, CLIP bridge, region encoder, SAM stack.
- dataset: mixed GLaMM datasets plus SynthScars/LEGION GCG loader.
- eval: preprocessing, mask utilities, flat-folder DDP dataset and distributed setup.
- mmdet: vendored MMDetection code used by region feature extraction.
- requirements: defender/default and controller/regenerator dependency locks.
- tools: token constants and training/inference helpers.
